# 2026-10-23

## 项目：D:/ashare-review（复盘罗盘·游资版，FastAPI + Vue3 + SQLite）

### 本轮完成的修复（均已通过测试/冒烟）

**时点与日期口径**
- `core/utils.py` 新增 `current_trade_date()`：09:15 后返回当天（盘中要能看到正在发生的这天），盘前/非交易日回退最近收盘日。`last_trade_day()` 仍表示“已收盘交易日”，两者不能混用。
- `limitup._pool_em` 改为以请求日期为业务日期。东财 `date` 参数有效但 `qdate` 固定返回最近交易日，之前用 qdate 会导致历史日期被判为“源日期不一致”而返回空。
- `sentiment._breadth_em` 增加日期校验：东财涨跌分布 `date` 参数不生效，返回日期与请求不一致时判缺失。
- `limitup.history_depth_ok(d)` = `d == current_trade_date()`。实时行情只代表一个时段，更早日期用它就是把未来数据回填历史。
- `sentiment.core` 仅在 15:05 后（`_is_final_trade_date`）落库，盘中刷新不再覆盖当天记录。
- `report.build` 重写入口守卫：目标日 ≠ 当前行情时段时只能读冻结快照，无快照抛 ValueError（API 409）；目标日未收盘直接拒绝生成。

**评分与主线**
- `sectors.line_confirm()` 抽出四维确认纯函数（涨停≥4家、有连板龙头、涨幅>2%、主力净流入>0），返回缺口列表；`main_line` 输出 `confirmed_lines`、`confirmed`、`confirm_gaps`、`taxonomy_ok`、`warnings`。
- 板块源增加腾讯降级 `_boards_tx`（`proxy.finance.qq.com/.../getRank`，含 `zljlr` 主力净流入）。注意腾讯是申万一级口径，与东财细分行业名称对不上，`taxonomy_ok=False` 时四维确认判不可用，不能当成“没有主线”。
- 报告主线清晰度只按 confirmed 计算：数据缺失→中性50；有涨停集中但无一确认→30。
- 选股器 `hot` 改为 `confirmed_lines`；`_main_line` 无确认主线时返回空并说明。
- `assess_data_quality`：板块缺失降为 warning（limited），mock 仍是 blocker；新增 `sector.taxonomy` 警告。

**新增功能：次日竞价确认（游资缺失环节）**
- `services/auction.py`：`session_state()` 时段判定、`judge_auction()` 规则纯函数（涨停排队 unbuyable / 高开超限 avoid / 低开<-3% avoid / 量能不足 weak / 达标 pass）、`build()` 汇总候选与报价。
- 关键修正：量能比原先用 `item.get("amount")`（不存在）导致恒为 None，改为 `amount_yi`；非竞价时段 `gap`、`auction_amount_yi` 一律置空，不再用当日涨幅冒充竞价高开。
- 前端 `views/Auction.vue` 竞价窗口内 15s 自动刷新并 `onBeforeUnmount` 清理；路由 `/auction`，API `GET /auction`。
