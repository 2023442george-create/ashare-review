- `scripts/launch.cmd` + 桌面 `复盘罗盘.cmd`：双击入口，失败会 `pause` 留住报错。
- `scripts/install_shortcut.ps1`：生成带 `assets/app.ico` 的 .lnk。**必须用户手动跑一次**，
  因为 Agent 侧 PowerShell 被策略禁止实例化 COM（WScript.Shell），不能代劳。
- `scripts/make_icon.py`：纯标准库画 64×64 图标（超采样 + 手写 PNG/ICO），不引入 Pillow。

### 四个踩过的坑

1. **PS 5.1 需要 UTF-8 BOM**：无 BOM 的中文 .ps1 会被当 GBK 读，字符串终止符解析失败。
   `Edit` 工具保存后要重新加 BOM（`UTF8Encoding($true)`）。
2. **`Start-Process` 会崩**：本机同时存在 `HTTPS_PROXY` 和 `https_proxy`，
   PS 5.1 重建环境变量字典时报「已添加项」。改用 `[Diagnostics.Process]::Start(ProcessStartInfo)`。
3. **`System.Net.Http` 默认没加载**：`New-Object HttpClientHandler` 直接「找不到类型」，
   导致健康检查永远 false、脚本误判启动失败。改用 `WebRequest` + `Proxy = $null`。
4. **隐藏窗口没有 stdout 句柄**：`print` 会挂。`run.py` 新增 `REVIEW_LOG`，
   自己把 stdout/stderr 重定向到文件。

### 停止脚本

- `scripts/stop.ps1` + `stop.cmd`：**必须三路定位**（pid 文件 / 端口监听者 / 命令行含 `ashare-review.*run.py`）。
  实测启动进程（pid 文件里那个）和真正 bind 端口的进程**不是同一个**，只杀 pid 会留下孤儿进程占着端口。
