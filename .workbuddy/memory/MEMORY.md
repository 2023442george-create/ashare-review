# ashare-review 项目约定

## 分支与改动

- **分支由用户手动创建/切换**。不要自动 `git switch`、不要装自动建分支的 hook。
  需要开分支时由用户提出，或用户自己执行。
- 动代码前先说明当前在哪个分支；如果工作区有未提交改动，先告知再改。
- 每次完成一批可交付改动后 `git commit`，保持工作区干净，便于识别“文件被整批回退”。

## 端口

- 默认 **18080**。`run.py` 会自动探测可用端口并打印实际地址（候选 18080/18081/18888/19090/28080/9090/8088/8080）。
- 不要改回 8000 / 8088：这两个已被 Windows「TCP 排除端口范围」吞掉，绑定报 `WinError 10013`。

## 数据源事实（已实测，勿重复试错）

- 东财 `push2 / push2delay / 82.push2 / 17.push2`：直连与走代理均被 reset，板块与 K 线不可用。
- 同花顺 `data.10jqka.com.cn`：ajax 取数返回 **401**，需 JS 计算 `hexin-v`，纯 HTTP 不可用，**不要再尝试**。
- 腾讯 `proxy.finance.qq.com/cgi/cgi-bin/rank/pt/getRank`：可用，`hy`=31 个申万一级，`gn`=概念，带涨幅与主力净流入。
- 新浪 `newSinaHy.php`：可用，49 个旧版行业，只有涨幅和成交额，无主力资金。
- 环境有全局代理 `127.0.0.1:4653` 且 `NO_PROXY` 为空，httpx 会继承；访问 localhost 时 curl 需加 `--noproxy '*'`。

## 口径

- 涨停池 `industry` 是东财细分行业（`通用设备`/`汽车零部`，会被截断成 4 字）；板块榜是申万一级。
  两者靠 `services/industry_map.py` 归并，**只做分类不改数值**。
- 四维确认：涨停家数 ≥4、最高板 ≥2、板块涨幅 >2%、主力净流入 >0。数据缺失必须记 `None` 并报缺口，**不得按 0 计**。
- 报告里的“收盘溢价”是可成交口径统计，不是打板收益；开盘不可成交的样本已剔除（`unbuyable_count`）。
