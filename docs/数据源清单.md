# 数据源清单（全部免费 · 多源备用）

> 所有接口均为公开免费接口，无需 token。表中「状态」为 2026-09 实测结果。
> 失败自动切换的机制见 `backend/app/core/cache.py` 的 `chain()` 与 `http.py` 的主机熔断。

## 1. 东方财富（主力源）

| 用途 | 接口 | 备注 |
|---|---|---|
| 实时行情/榜单 | `https://push2.eastmoney.com/api/qt/ulist.np/get`、`/api/qt/clist/get` | 部分网络会被限流；自动降级 `push2delay.eastmoney.com`（延时行情，复盘够用）与 `82./17.push2` |
| K线 | `https://push2his.eastmoney.com/api/qt/stock/kline/get` | 自带成交额字段，用于量能历史 |
| 涨停池 | `https://push2ex.eastmoney.com/getTopicZTPool?ut=...&dpt=wz.ztzt&date=YYYYMMDD` | 含封单额、首封/末封时间、炸板次数、连板数、行业 |
| 炸板池 / 跌停池 | `getTopicZBPool` / `getTopicDTPool` | 同上 |
| 涨跌分布 | `getTopicZDFenBu` | 全市场涨跌家数直方图（key 11=涨停，-11=跌停） |
| 龙虎榜明细 | `https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_DAILYBILLBOARD_DETAILSNEW` | 含买卖额、净额、上榜原因 |
| 龙虎榜席位 | `reportName=RPT_BILLBOARD_DAILYDETAILSBUY` / `...SELL` | 营业部名称、3日胜率、上榜次数 |
| 两融历史 | `reportName=RPTA_RZRQ_LSHJ` | 融资余额、净买入 |
| 沪深港通 | `reportName=RPT_MUTUAL_DEAL_HISTORY` | 北向实时净买入已停发，用成交额口径 |
| 7×24 快讯 | `https://np-weblist.eastmoney.com/comm/web/getFastNewsList` | 需 `req_trace` 参数 |

## 2. 腾讯财经（行情首选，HTTP 即可）

| 用途 | 接口 | 备注 |
|---|---|---|
| 实时行情 | `http://qt.gtimg.cn/q=sh000001,sz399001,...` | GBK 编码；字段：3=现价 4=昨收 31=涨跌 32=涨跌幅 37=成交额(万) |
| 日/周/月K | `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh000001,day,,,320,qfq` | 6 字段（无成交额），系统用「量比法」推算历史成交额 |
| 全球指数 | 同上，代码 `usDJI/usIXIC/usINX/usHXC/hkHSI/hkHSTECH/hkHSCEI/usVIX` | VIX 更新较慢，界面会标「数据偏旧」 |

## 6. 可选 Python 库兜底

| 库 | 作用 |
|---|---|
| `akshare` | 聚合东财/新浪/同花顺几十个免费接口；涨停池、板块资金流、龙虎榜均可兜底 |

## 7. 限流与合规注意

1. 所有请求带轮换 UA、并发上限 12、失败退避重试；单域名连续失败 2 次熔断 4 分钟。
2. 数据仅用于个人研究复盘；请勿高频抓取或商用转发。
3. 行情为**快照/延时**口径，不保证与交易所实时一致；交易决策请以券商终端为准。
4. 接口字段可能随站点改版变化，适配层集中在 `backend/app/sources/`，改一处即可。
