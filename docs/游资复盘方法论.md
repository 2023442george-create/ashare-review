# 游资复盘方法论（10 年短线视角）

> 这份文档回答一个问题：**一个靠短线吃饭的人，每天收盘后到底看什么、按什么顺序看、看到什么信号做什么动作。**
> 软件里的每一个指标、每一个页面，都是这份方法论的落地。先读它，再打开软件，你会知道每个数字在说什么。

---

## 0. 总纲：游资看盘的三个层次

1. **情绪层（最重要）**：市场愿不愿意给溢价。涨停家数、连板高度、炸板率、隔日溢价——这些决定"能不能做、做多重"。
2. **结构层**：钱集中在哪。主线题材、板块资金流、连板梯队、龙虎榜席位——决定"做什么"。
3. **环境层**：外围与宏观给不给脸色。美股/费半/中概/日韩/港股/A50/汇率/利率——决定"开盘怎么应对"。

**指数只是结果，不是原因。** 游资可以不在乎上证今天是 3900 还是 3800，但必须在乎：今天打板明天能不能赚钱。

---

## 1. 情绪层：每天必看的 8 个数字

### 1.1 涨停家数 / 跌停家数
- **涨停 ≥ 90 家**：情绪强，赚钱效应扩散，可以积极。
- **40~90 家**：正常偏暖，做主线。
- **< 40 家**：情绪弱，只做确定性龙头或空仓。
- **跌停 > 10 家**：系统性杀跌，当日不开新仓，这是铁律。
- 看**趋势**比看绝对值重要：连续 3 天递增 = 发酵期；高位突然腰斩 = 退潮开始。

### 1.2 最高连板（空间板）
- 空间板是市场的"想象力天花板"。2~3 板 = 情绪低迷；4~5 板 = 主升；6 板以上 = 情绪高位。
- **空间板断板（跌停或大面）= 情绪见顶的第一信号**，比指数下跌早 1~2 天。
- 关注**断层**：如果 4 板和 2 板之间没有 3 板，说明晋级通道断裂，接力胜率骤降。

### 1.3 炸板率 = 炸板数 /（涨停+炸板）
- **< 20%**：封板坚决，资金一致，适合打板。
- **20~35%**：正常分歧，做主线龙头。
- **> 35%**：分歧巨大，"打板=接飞刀"，改为低吸或空仓。
- 炸板率与涨停家数**同时创新高**，是典型的顶部特征（人多但封不住）。

### 1.4 昨日涨停今日溢价（隔日赚钱效应）
- 这是**打板策略的真实收益率**：把昨天所有涨停股今天的涨跌幅取平均。
- **> +3%**：打板有肉，可以上仓位。
- **0 ~ +3%**：有溢价但薄，只做最强主线。
- **< 0**：打板亏钱，**立即停止打板**，这是最重要的止损信号。
- 配合"红盘率"（昨日涨停今日收红的比例）一起看，>60% 才算健康。

### 1.5 晋级率
- 昨日涨停 → 今日继续涨停的比例。**>30% 梯队健康；<15% 接力资金撤退。**
- 首板晋级率（昨首板→今二板）更能反映"新题材能不能走出来"。

### 1.6 上涨家数占比（市场宽度）
- **> 60%**：普涨，题材百花齐放，可以做首板、做补涨。
- **40~60%**：结构性行情，只做主线。
- **< 40%**：分化/普跌，只碰龙头或空仓。
- 宽度与指数背离时信宽度：指数红但上涨家数少 = 权重护盘，题材在跌，**最容易亏钱的结构**。

### 1.7 两市成交额与量能结构
- **< 8000 亿**：地量冰点，存量博弈，只做确定性，仓位 ≤3 成。
- **8000~1.2 万亿**：存量轮动，题材持续性差，避免追高。
- **1.2~1.8 万亿**：温和放量，游资最舒服的区间。
- **> 1.8 万亿**：增量入场，可提升仓位；但**天量之后防天量分歧**，连续两天巨量滞涨要减仓。
- 看**相对变化**：比 5 日均量放大 20% 以上才算有效放量；缩量上涨是背离。

### 1.8 涨停封单质量（封成比 / 封单÷流通市值）
- 封成比 = 封单额 ÷ 当日成交额。**>30% 极强，10~30% 良好，<5% 随时开板。**
- 封单/流通市值 > 3% 属于"强力封板"，通常是龙头特征。
- 一字板买不进，没有操作价值；**秒板（9:35 前封）+ 高封成比**才是游资最爱的首板形态。
- 尾盘板（14:45 后封）与烂板（炸板≥2 次）次日溢价差，列入风险池。

## 2. 情绪周期：五阶段与对应动作

| 阶段 | 特征 | 仓位 | 打法 |
|---|---|---|---|
| **冰点** | 涨停<25、跌停≥涨停、空间板≤2、溢价<0 | 0~1 成 | 空仓等待；盯三个反转信号：跌停清零、首板>30、竞价出现高开5%的票 |
| **修复** | 情绪分回升、首板放量、出现 2~3 板 | 2~4 成 | 做首板与低位反包，不追高 |
| **发酵** | 主线清晰、涨停 60~100、空间板 4~5、炸板率<30% | 6~8 成 | **游资最好的窗口**：打板、半路、低吸都可以，集中持仓主线 |
| **高潮** | 涨停>100 或空间板≥6、一致性极强 | 4~5 成并逐日兑现 | 只做龙头，不接跟风；警惕"涨停新高+炸板率新高" |
| **退潮** | 空间板断板、跌停潮、溢价转负 | 0~2 成 | 禁止接力，只做超跌反抽，保命第一 |

**判断顺序**：先看情绪分趋势（升/降），再看空间板是否抬升，最后看炸板率是否同步恶化。三者同向时信号最可靠。

## 3. 结构层：怎么找主线

主线 = **涨停家数多 + 有连板龙头 + 板块涨幅居前 + 主力净流入为正**，四个条件同时满足。

1. **先看涨停池的行业分布**：哪个行业批量涨停（≥4 家）且有 2 板以上，就是候选主线。
2. **再看板块涨幅与资金流**：候选主线当日板块涨幅应 >2% 且主力净流入为正；若"涨停多但板块资金净流出"，警惕拉高出货。
3. **看持续性**：主线至少连续 2 天出现在榜单前列；一日游题材不做。
4. **主线内选龙头**：优先连板高度最高者；若龙头一字买不进，做同板块**封单最大的二板**或**放量首板补涨**。
5. **杂毛回避**：非主线板块的首板，即使形态好也降低预期——资金不在那里。

**资金流交叉验证**：个股主力净流入 TOP50 与主线成分重合度高 = 资金真在做；若 TOP50 全是权重白马而题材无流入 = 风格切大盘，降仓。

## 4. 龙虎榜：看"谁在买"比看"买多少"重要

- **机构专用**净买入：题材获得机构认可，持续性通常好于纯游资票，可跟踪 2~3 天。
- **顶级/一线游资**（章盟主、赵老哥系、佛山系、溧阳路等）：代表主线级别资金，进场往往意味着行情没走完。
- **拉萨天团（东财拉萨系营业部）**：散户追涨集中营。**大额买入常是情绪末端信号**，次日冲高回落概率大——看到拉萨接盘，反而是减仓理由。
- **量化通道/券商总部席位**：高频对倒，方向意义弱，不要据此判断多空。
- 看**净买入占成交额比例**：>20% 说明资金控盘意愿强；<5% 只是路过。
- 结合席位**3 日胜率**（交易所口径）：胜率<40% 的席位重仓票，次日谨慎。

## 5. 环境层：外围市场与"开盘前 30 分钟"

### 5.1 必看清单（按重要性）
1. **富时中国 A50 期货**：A 股开盘前唯一实时先行指标。>+0.5% 高开概率大，竞价可积极；<-0.5% 低开，竞价不追。
2. **纳斯达克中国金龙指数**：中概隔夜表现，与 A 股/港股情绪同步性最高。
3. **费城半导体（SOX）**：A 股芯片/存储/设备的直接锚。+2% 以上，半导体链大概率高开（注意高开兑现风险）。
4. **纳指/标普**：全球科技与风险偏好，影响 AI、算力主线的开盘溢价。
5. **恒生科技/恒生指数**：与 A 股同步交易，港股弱则 A 股难独立走强。
6. **日经 225 / 韩国 KOSPI**：亚太风险偏好；韩股权重含三星/海力士，与存储链联动。
7. **离岸人民币（CNH）/ 美元指数**：贬值加速时警惕权重护盘失败、题材杀跌。
8. **VIX / 美债 10Y**：全球估值分母。VIX>25 或 10Y 快速上行 → 高估值成长（创业板/科创）承压，降仓。
9. **原油/黄金**：通胀与避险，影响周期、贵金属、航空等板块的日内题材。

### 5.2 传导速查
- 费半大涨 → 半导体/存储/设备/PCB 利好；但**高开>3% 不追**，等回踩。
- 金龙大涨 → 港股互联网映射、中特估、消费情绪回暖。
- 日经/韩股大跌 → 亚太科技链、出口链承压。
- 人民币急贬 → 航空/造纸（外币负债）利空，外资重仓白马承压。
- 原油大涨 → 石油石化/油运利好，航空/化工下游利空。
- 黄金大涨 → 贵金属板块题材，同时提示避险情绪升温（股票 risk-off）。

## 6. 消息面：找"催化"，不是读新闻

1. 只关心**能映射到板块/个股**的消息；纯宏观口水话忽略。
2. 区分**新催化**（首次出现 → 可做首板）与**旧闻发酵**（已炒过 → 只做补涨或回避）。
3. 消息必须与**当日涨停结构对照**：
   - 有消息 + 有涨停 = 主线确认，可做；
   - 有消息 + 无涨停 = 资金不认可，观望；
   - 无消息 + 有涨停 = 资金先行，往往更持久（关注龙虎榜找原因）。
4. 盘后重大政策/产业消息：次日竞价看**高开幅度 + 承接量**。高开 3~5% 且量比>3 可参与；高开>7% 多为兑现点。
5. 用"消息热词"统计当天资金在炒什么：热词与涨停行业重合 = 情绪与消息共振，胜率高。

## 7. 一日流程（SOP）

| 时间 | 动作 |
|---|---|
| 08:30-09:15 | 看隔夜美股/费半/金龙、A50 期货、离岸人民币；读盘后重大消息；定今日仓位上限与候选池 |
| 09:15-09:25 | 竞价：看候选票高开幅度与竞价量，确认/放弃；看两市竞价总额判断量能 |
| 09:30-10:00 | 观察期：确认主线是否延续、空间板是否晋级；不追第一个涨停 |
| 10:00-11:30 | 执行：主线首板/二板打板或半路；记录每笔逻辑 |
| 13:00-14:30 | 观察炸板率与跌停数变化；情绪转弱立即停止开新仓 |
| 14:30-15:00 | 尾盘：决定是否留仓；尾盘板谨慎参与 |
| 15:00-16:00 | **复盘（本软件）**：情绪分/周期、主线、天梯、龙虎榜、外围、消息 → 生成报告、写笔记 |
| 17:00-19:00 | 龙虎榜公布后：核对席位，修正对主线的判断 |
| 20:00-22:00 | 制定明日预案：候选池、触发条件、止损位、仓位 |

## 8. 风控纪律（比选股更重要）

1. 单票不超过总仓 30%；单题材不超过 60%。
2. 打板失败（次日竞价不及预期/低开>3%）：**竞价直接砍**，不幻想。
3. 跌停家数 > 10：当日不开新仓。
4. 账户回撤 5%：强制减半仓；回撤 10%：停止交易 2 天，只复盘。
5. 情绪退潮期（空间板断板+跌停潮）：禁止接力，只做超跌反抽。
6. 永远先想"错了怎么办"，再想"对了赚多少"。
